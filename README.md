# 🚀 Overview

Retailers generate enormous amounts of transaction data every day.

Hidden inside these transactions are purchasing patterns that can significantly increase revenue when discovered correctly.

This platform automatically analyzes transaction datasets using **Market Basket Analysis**, discovers **association rules**, and transforms them into **AI-powered business insights**.

Instead of only showing statistical values like **Support**, **Confidence**, and **Lift**, the platform explains what those numbers actually mean for business owners.

# ⚙ Installation

Clone Repository

```bash
git clone https://github.com/aniketsinghgold-dev/market-basket-analysis.git
```

```bash
cd market-basket-analysis
```

---

## Backend

```bash
cd backend

pip install -r requirements.txt

python main.py
```

---

## Frontend

```bash
cd frontend

npm install

npm run dev
```
